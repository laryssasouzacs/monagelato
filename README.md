# 🍦MonaGelato — Landing Page
 
Landing page de alta conversão desenvolvida para a **MonaGelato**, marca de sorvetes artesanais que vende via delivery.
 
🔗 **[Ver site publicado](https://laryssasouzacs.github.io/monagelato/)**
 
## Sobre o projeto
 
O objetivo desta página é transformar visitantes — principalmente seguidores do Instagram da marca — em clientes, direcionando-os de forma clara para o pedido via 99 Food.
 
A página foi construída com foco em:
- **Conversão (CRO):** jornada clara de Atenção → Interesse → Desejo → Ação, com CTAs objetivos
- **Copywriting alinhado à marca:** tom de voz pessoal e afetivo, refletindo como a proprietária se comunica com sua audiência
- **Performance e acessibilidade:** HTML semântico, lazy loading, contraste adequado e navegação por teclado

## Tecnologias
 
- HTML5 semântico
- CSS3 (Grid, Flexbox, Custom Properties)
- [Bootstrap Icons](https://icons.getbootstrap.com/) via CDN
- Google Fonts (Playfair Display + Poppins)
Sem frameworks ou bibliotecas de JavaScript — projeto propositalmente enxuto, priorizando velocidade de carregamento.
