# 🍦Gelato House — Landing Page

Landing page de alta conversão desenvolvida para a **Gelato House**, marca fictícia de sorvetes artesanais criada como projeto de portfólio.

🔗 **[Ver site publicado](https://laryssasouzacs.github.io/gelato-house/)**

## Sobre o projeto

Este projeto nasceu como uma landing page real para uma marca de sorvetes artesanais e foi depois transformado em um projeto autoral fictício — a "Gelato House" — usado como case de portfólio, com liberdade para explorar identidade visual, estrutura e copywriting do zero.

A página foi construída com foco em:
- **Conversão (CRO):** jornada clara de Atenção → Interesse → Desejo → Ação, com CTAs objetivos
- **Copywriting de marca:** tom de voz caloroso e direto, adaptado ao universo de uma gelateria artesanal
- **Navegação real:** header fixo com âncoras de rolagem suave (Cardápio, Sobre, Diferenciais, Como Pedir)
- **Performance e acessibilidade:** HTML semântico, lazy loading, contraste adequado e navegação por teclado

## Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, Custom Properties, scroll suave via CSS)
- [Bootstrap Icons](https://icons.getbootstrap.com/) via CDN
- Google Fonts (Fraunces + Work Sans)

Sem frameworks ou bibliotecas de JavaScript — projeto propositalmente enxuto, priorizando velocidade de carregamento.
